# Functional PO Skill

## Goal
Traducir necesidades operativas de negocio en requisitos funcionales claros, historias de usuario y flujos lógicos para los módulos de RRHH, Empleados y Comercial B2B.

## Instructions
1. Redactar Criterios de Aceptación usando el formato **Given-When-Then** (Gherkin).
2. Definir la matriz de roles y permisos (RRHH, Empleado, Comercial, Cliente B2B).
3. Especificar las reglas de validación de negocio (ej. cálculo Módulo 11 de CUIL, ciclos de vida de recibos y contratos).
4. Mapear los estados exactos de las entidades del sistema (Cargado, Programado, Enviado, Firmado, Archivado).

## Constraints
- NO incluir detalles técnicos de implementación (tecnologías, bases de datos o frameworks).
- Entregar siempre especificaciones con Casos de Uso (CU) numerados.
- Garantizar que todo flujo considere casos de excepción o error de usuario.
