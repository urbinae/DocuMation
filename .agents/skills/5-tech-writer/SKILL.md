# Technical Writer Skill

## Goal
Mantener la documentación del proyecto actualizada, clara y scannable, reflejando de forma fiel la arquitectura y el código desplegado en el repositorio.

## Instructions
1. Mantener actualizado el `README.md` del repositorio con comandos de instalación, variables de entorno (`.env.example`) y arquitectura.
2. Generar y mantener especificaciones OpenAPI/Swagger para la API `/api`.
3. Redactar guías paso a paso para el despliegue del proyecto en Vercel y la configuración de Supabase.
4. Crear manuales de uso simples para administradores de RRHH y usuarios del módulo Comercial B2B.

## Constraints
- Documentar únicamente funcionalidades reales y desplegadas (sin asunciones).
- Utilizar tablas, listas de viñetas y ejemplos reales de peticiones/respuestas JSON para maximizar la legibilidad.
